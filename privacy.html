Політика конфіденційності та умови — Кіно про нас

Ця сторінка пояснює, які дані збирає студія «Кіно про нас», навіщо, як ми їх бережемо, а також умови замовлення пісні-мультика. Оновлено: 2 жовтня 2026.

1. Які дані ми отримуємо

  • Відповіді в анкеті: ім'я людини, якій дарують подарунок, привід, спогади й побажання, які ви самі пишете.
  • Фото, які ви надсилаєте, — лише щоб намалювати героїв мультфільму схожими на ваших рідних.
  • Ваше ім'я та нік у Telegram — щоб надіслати готову роботу й відповідати вам.
  • Скриншот оплати — щоб підтвердити замовлення. Номерів карток клієнтів ми не отримуємо і не зберігаємо.

2. Навіщо

Лише щоб створити й доставити вашу персональну пісню й мультфільм, внести правки й відповісти на питання. Ми не продаємо й не передаємо ваші дані для реклами.

3. Хто ще обробляє дані

Для створення тексту, музики, зображень і відео ми використовуємо сторонні сервіси генерації та обробки (обробники даних). Вони отримують лише те, що потрібно для вашого замовлення: текст анкети й фото. Зв'язок із вами відбувається через Telegram.

4. Публікація

Роботи клієнтів ми не публікуємо і не використовуємо в рекламі. Відгук публікуємо лише з вашого прямого дозволу — тільки з іменем, без фото. У рекламі студії використовуються лише вигадані персонажі.

5. Зберігання й видалення

Зберігаємо дані замовлення, доки вони потрібні для виконання, правок і підтримки. Щоб видалити свої дані й фото, напишіть у підтримку бота — видалимо протягом 7 днів.

6. Дані Google / YouTube

Застосунок студії використовує YouTube API лише для того, щоб завантажувати власні відео студії на власний канал студії. Ми не отримуємо доступу до даних інших користувачів Google і не зберігаємо їх. Використання даних, отриманих через API Google, відповідає Політиці щодо даних користувачів служб API Google, зокрема вимогам обмеженого використання (Limited Use). Також діють Умови використання YouTube і Політика конфіденційності Google.

7. Умови замовлення

  • Ви отримуєте персональну пісню (mp3), мультфільм на всю пісню і версію для сторіс.
  • Ціна — 799 грн (або за промокодом), оплата до початку роботи.
  • Термін — до 24 годин після підтвердження оплати. Не встигли з нашої вини — повертаємо кошти за бажанням. Експрес (+150 грн) — до 3 годин; не встигли — повертаємо доплату.
  • Правки — безкоштовно, доки результат вас не влаштує.
  • Повернення — до початку роботи повністю; після початку — якщо ми не виконали замовлення.
  • Пісня-мультик — для особистого використання: подарунок, показ рідним, ваші соцмережі. Не для продажу чи музичних платформ.

English summary (for Google and TikTok reviewers)

Kino pro nas is a small Ukrainian studio that creates personal songs and animated films for families. Contact: Telegram bot @Kinopronas_bot (Support).

Google / YouTube API. Our desktop app "KinoProNas Publisher" uses the YouTube Data API only to upload the studio's own promotional videos to the studio's own YouTube channel (the only scope requested is youtube.upload). We do not access, store or share data of any other Google users. The OAuth refresh token is stored only on the studio's own computer. Our use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using the app, the channel owner agrees to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

TikTok API. The same app uses TikTok Login Kit and the Content Posting API only to post the studio's own videos to the studio's own TikTok account, after the account owner chooses the privacy setting and confirms each post. We store only the access token of the studio's own account; no data of other TikTok users is collected.

Customer data. Customers' questionnaire answers and photos are used only to create their order and are never published or used in advertising. Deletion on request within 7 days via the bot's Support.
